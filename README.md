# rokuyan

医療系企業で、AI 活用と自動テストのリーダーを務めるバックエンドエンジニアです。
企画から設計、実装、効果検証まで、0 → 1 のプロダクト開発を一貫して担当しています。

## Career

### 医療系企業（現職）— AI 活用・自動テストなど複数開発プロジェクトのリーダー

- 🚀 **開発チームの生産性を 1 年で 1.6 倍に**
  AI 活用と自動テストの整備をリードし、1 人あたりのチケット消化数が平均 160% になった

### SIer — 開発リーダー

- 🛒 **EC サイトの検索リランキング基盤**
  複数の ML モデルを A/B テストで比較できる API を設計した。ML モデリングと効果検証の設計を担当

### コールセンター向けサービス企業 - 開発メンバー

- 🔍 **13 億レコードの検索を 5 秒 → 0.5 秒に**
  全文検索が不要な要件だと見極め、Redis でインデックスを設計し直した
- 📞 **架電先を選ぶための分析基盤**
  OpenSearch で業界・規模のあいまい検索ができるようにし、機械学習で時間帯ごとの最適な架電先を出せるようにした
- 📊 **毎日 90 分かかっていた報告業務をゼロに**
  架電結果の集計から請求書・分析レポートの作成、メール送信までをすべて自動化した
